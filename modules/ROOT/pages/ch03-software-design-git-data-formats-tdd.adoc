== 3.1 Introduction: The Spaghetti Script Catastrophe

An operations engineer writes a 1,200-line monolithic script named `audit_all_switches_v2.py`. It has zero modular functions, hardcoded IP addresses, and no version control. When an unexpected exception occurs, the script terminates halfway through reconfiguring 80 distribution switches, leaving the campus network split between two incompatible MTU settings.

Building mission-critical network automation requires professional software engineering disciplines: clean architectural patterns, disciplined Git version control, structured data formats, and automated unit testing.

== 3.2 Software Design Patterns for Network Engineering

image::ch03/g3-1-mvc-network-automation.png[Model-View-Controller Applied to Network Automation]

In network automation, the **Model-View-Controller (MVC)** pattern decouples data from presentation:
* **Model:** Python classes and data structures representing network inventory and interface state.
* **View:** Formatters that render data into human CLI tables, HTML reports, or Webex alert cards.
* **Controller:** Orchestration logic parsing CLI arguments, querying devices, and updating views.

=== Parsing Formats in Python

[source,python]
----
import json, yaml, xmltodict

# JSON parsing
json_data = json.loads('{"interface": "GigabitEthernet1", "enabled": true}')

# YAML parsing
yaml_data = yaml.safe_load("interface: GigabitEthernet1\nenabled: true")

# XML parsing
xml_data = xmltodict.parse("<interface><name>GigabitEthernet1</name></interface>")
----

== 3.5 Unit Testing and Test-Driven Development (TDD)

Test-driven development ensures network scripts handle malformed data and transport failures gracefully before touching physical hardware.

.Video 3.4: Test-Driven Development (TDD) for Network Scripts with Python unittest
[video, width=800, height=450]
video::v3-4-tdd-unittest.mp4[poster=v3-4-poster.png, captions=v3-4-captions.vtt]

image::ch03/g3-6-tdd-cycle.png[Test-Driven Development Red-Green-Refactor Cycle]

image::ch03/g3-7-test-pyramid-networking.png[The Testing Pyramid for Network Automation]

[source,python]
----
import unittest

def parse_vlan_id(vlan_str: str) -> int:
    try:
        vid = int(vlan_str)
        if 1 <= vid <= 4094:
            return vid
        raise ValueError("VLAN ID out of range")
    except (TypeError, ValueError) as err:
        raise ValueError(f"Invalid VLAN: {err}") from err

class TestVlanParser(unittest.TestCase):
    def test_valid_vlan(self):
        self.assertEqual(parse_vlan_id("100"), 100)

    def test_out_of_range_vlan(self):
        with self.assertRaises(ValueError):
            parse_vlan_id("5000")
----

== 3.8 Key Terms

pull request (PR):: A proposed set of changes submitted to a repository for peer review prior to merging into a mainline branch.
serialization:: Converting in-memory data structures into a standardized text representation for storage or network transmission.
TDD:: A programming discipline where automated tests are authored before writing the functional code.

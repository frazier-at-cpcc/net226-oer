== 4.2 Architectural Paradigms: REST, RPC, and Webhooks

image::ch04/g4-1-api-architecture-comparison.png[Comparison of REST, RPC, SOAP, and Webhooks]

* **REST (Representational State Transfer):** Resource-based (`GET /api/v1/devices`), stateless, cacheable, uniform interface.
* **RPC (Remote Procedure Call):** Action-based (`POST /rebootRouter`), tightly coupled functions.
* **Webhooks:** Inverted event-driven architecture; servers push notifications via HTTP POST to a listener when an event occurs.

=== HTTP Verbs & Status Codes
* **GET (200 OK):** Read resource state idempotently.
* **POST (201 Created):** Create a new resource.
* **PUT (200/204):** Completely replace an existing resource.
* **PATCH (200 OK):** Partially update specific fields.
* **DELETE (204 No Content):** Remove a resource.
* **401 Unauthorized vs 403 Forbidden:** 401 indicates missing or invalid credentials; 403 indicates authenticated credentials lack necessary permissions.
* **429 Too Many Requests:** Server rate limit exceeded; inspect `Retry-After` header.

== 4.4 API Authentication and Token Management

image::ch04/g4-4-authentication-mechanisms.png[API Authentication Spectrum: Basic Auth to OAuth 2.0]

Never hardcode credentials in source code. Load tokens dynamically from environment variables:
[source,python]
----
import os

API_KEY = os.environ.get("CISCO_API_KEY")
if not API_KEY:
    raise ValueError("Missing CISCO_API_KEY environment variable")
----

== 4.6 Developing a Robust Python API Client

.Video 4.4: Building Resilient Python API Clients: Authentication, Pagination, and Exponential Backoff
[video, width=800, height=450]
video::v4-4-resilient-python-client.mp4[poster=v4-4-poster.png, captions=v4-4-captions.vtt]

image::ch04/g4-6-python-requests-lifecycle.png[Python requests Client Execution Lifecycle and Error Handling]

[source,python]
----
import os, time, requests

def get_devices(network_id: str) -> list:
    url = f"https://api.meraki.com/api/v1/networks/{network_id}/devices"
    headers = {"X-Cisco-Meraki-API-Key": os.environ["MERAKI_KEY"], "Accept": "application/json"}
    response = requests.get(url, headers=headers, timeout=10)
    if response.status_code == 429:
        wait = int(response.headers.get("Retry-After", 2))
        time.sleep(wait)
        return get_devices(network_id)
    response.raise_for_status()
    return response.json()
----

== 4.9 Key Terms

REST:: Representational State Transfer; an architectural pattern relying on stateless, client-server communication over standard HTTP.
Bearer Token:: A security token whose possession grants access to associated resources without further authentication.
idempotent:: An operation that produces the same result whether executed once or repeatedly.
